# Use Next.js (App Router) + MDX instead of Astro

The site is content-heavy (9 case studies) and SEO for an overseas audience matters, which favors Astro's raw performance. We chose Next.js + MDX anyway: it's a stack recruiters recognize instantly and quietly signals frontend/fullstack range without contradicting the backend-first narrative, whereas Astro is a less legible signal despite being the marginally better fit for a pure content site. Deployed on Vercel.
